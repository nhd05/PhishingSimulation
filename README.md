CyberSafe Training Simulator

An interactive security awareness training platform that teaches users how to recognize and respond to real-world cyber threats — through guided lessons and hands-on quizzes.


Overview


CyberSafe Training Simulator is a web-based learning application designed to help users build practical cybersecurity awareness. The platform covers the most common attack vectors that target everyday users and employees, combining engaging educational content with knowledge-check quizzes to reinforce learning.
This project was built as a training simulation to make security education accessible, interactive, and effective — without needing a technical background.

What It Does


Users move through a series of training modules, each focused on a key cybersecurity topic. After completing the material, they take a quiz to test their understanding before advancing.

Training Modules So Far: 
 

Phishing How to spot deceptive emails, fake links, and spoofed sender addresses

Social Engineering Recognizing manipulation tactics like pretexting, baiting, and impersonation

Password Security Creating strong passwords, using password managers, and avoiding common mistakes


Core Features

Interactive Lessons — Step-by-step content that walks users through real-world scenarios

Knowledge Quizzes — Multiple-choice questions that test comprehension after each module

Instant Feedback — Users learn why an answer is right or wrong, reinforcing correct behavior

Progress Tracking — Visual indicators showing which modules are complete
